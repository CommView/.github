## CommView Highlights

- **Packet List:** CommView packet list shows packets on a link you administer, one line at a time.
- **Protocol Tree:** CommView protocol tree opens one packet into layers so a lab can see header fields for a lesson.
- **Traffic Graph:** CommView traffic graph shows volume on that same link over the last stretch of time.
- **Alarm Rule:** CommView alarm rule notes when a host or a condition you named on your network becomes busy or quiet.
- **Session Rebuild:** CommView session rebuild presents a conversation from the packets you captured on that administered link.

---

## What Is CommView

CommView is a packet-reading helper for a network link you are allowed to administer, such as a classroom lab segment or a small office switch you manage. CommView packet list is the running list. CommView protocol tree is the opened packet. Students can learn what a header looks like on traffic from their own lab. An admin can see what their own link is doing during a quiet test.

CommView traffic graph gives the volume without reading every line. CommView alarm rule watches for a condition you set on that link, such as a host you manage becoming suddenly busy. CommView session rebuild turns packets from a conversation on that same link into a readable session for a lesson or a local troubleshooting hour. The boundary is the network you operate. It is not a guide for listening to networks you do not administer.

Begin on a quiet lab segment. Confirm CommView packet list and CommView protocol tree against traffic you generated yourself, such as a page load on a host you control. Then look at CommView traffic graph, add one CommView alarm rule for a host you manage, and try CommView session rebuild on that same short test. Keep the capture on your own link.

## Compatibility

| Component | Minimum | Recommended |
|-----------|---------|-------------|
| **Operating System** | Windows 10 | Windows 11 with the current CommView build |
| **Processor (CPU)** | Dual-core CPU | Modern multi-core CPU while the packet list is busy |
| **Memory (RAM)** | 4 GB | 8 GB or more during a longer read of your own link |
| **Storage** | Space for the helper and a short capture | Extra room for a lesson capture you are allowed to keep |
| **Permissions** | Standard user access where the adapter allows it | Admin rights on the monitoring PC for a link you administer |

CommView packet list should be used on a segment you administer. CommView session rebuild belongs to conversations on that same link, such as a test you started.

## Starting with CommView

Prerequisites: A compatible computer, a network link you administer, and permission to run CommView there.

1. **Prepare:** Choose a lab or office segment you control, and note one host you manage.
2. **Open The List:** Start CommView packet list and generate a small amount of traffic from that host.
3. **Open One Packet:** Use CommView protocol tree on a packet from your own test.
4. **See Volume:** Glance at CommView traffic graph while the test runs.
5. **Name An Alarm:** Add CommView alarm rule for the host you manage, such as a sudden busy mark.
6. **Rebuild A Test:** Use CommView session rebuild on the short conversation you just created, then stop when the lesson or check is done.
